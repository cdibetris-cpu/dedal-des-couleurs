# DEDAL DES COULEURS

University Web Publication project developed as part of a Digital Communication course.

## Project

DEDAL DES COULEURS is a responsive website for a Paris art gallery presenting modern and expressionist artworks.

The website was designed and developed with a focus on:

- Responsive web design
- Accessibility
- SEO
- Performance
- Semantic HTML
- User experience

## Pages

- Accueil / En Vedette
- Galerie
- À propos
- Contact

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive CSS Grid and Flexbox
- Git
- GitHub
- GitHub Pages
